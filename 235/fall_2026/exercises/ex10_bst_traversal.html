Learning Objectives

This exercise gives you practice with the basic operations on a binary search tree. By the end you should be able to:

  • write the three depth-first traversals (in-order, pre-order, post-order) recursively, and explain that they differ only in when the node is visited;
  • explain why in-order traversal of a binary search tree visits the values in increasing order;
  • replace recursion by an explicit std::stack, and see that the call stack and your own stack do the same job;
  • write a level-order (breadth-first) traversal with std::queue, the same idea you used in the maze solver;
  • compute the height of a tree and count its leaves with a short recursive function.
An analogy: walking through an office building Picture a tree as an office building. Each office (node) has a door to a left room and a door to a right room. Pre-order is the tour guide who announces an office before walking into its rooms. In-order visits the left rooms first, announces the office, and then does the right rooms. Post-order is the inspector who may only sign off on an office after both rooms behind it are done. Level-order instead visits the whole first floor, then the whole second floor, and so on.

The tree you work with A Node holds an int data and two pointers, left and right, which are nullptr when there is no child. The tree is a binary search tree: every value in the left subtree of a node is smaller than the node, and every value in the right subtree is larger. The provided buildTree makes such a tree from a list of values (a repeated value is ignored), and destroy frees it. All your functions only read the tree (the parameters are const Node*); none of them allocates or frees a node. The autograder checks that the tree is unchanged after every call.

Task A — Recursive traversals

Write inorder(), preorder() and postorder(). Each one appends the data values to the vector out in the order its name says:

FunctionOrder
inorderleft subtree, then the node, then right subtree
preorderthe node, then left subtree, then right subtree
postorderleft subtree, then right subtree, then the node

Do not clear out and do not sort it: the caller may already have put values there, and your function must leave them in place. An empty tree (root == nullptr) appends nothing.

Hint All three functions have the same shape. Decide what the base case is, and then decide where the line that records root->data goes relative to the two recursive calls.

Task B — Traversals with a stack

Write inorderIterative() and preorderIterative(). They produce exactly the same sequences as Task A, but without recursion: use a std::stack of node pointers (and, if you like, a traversal pointer named curr). Each function returns the values it visits.

The recursive versions use the call stack, which holds one frame per node on the path from the root. A very deep tree can overflow it. Your explicit stack lives on the heap and can grow much further. Requirements: write both functions as loops. Inside each function use a std::stack directly (do not move the work into a helper function), and do not call the function itself. The autograder checks this by reading your code: a Task B function that calls itself or does not mention std::stack in its own body earns no credit for Task B. It also builds a tree 1,000,000 nodes deep (in a separate run, so a crash there costs only that 5-point check): this tests that your functions cope with a very deep tree (a recursive function overflows the call stack on it).

Hint In-order: what must you remember while you walk down the left spine? Pre-order: a stack gives back the last item you pushed first. Which child must therefore be pushed last?

Task C — levelOrder()

Return the values level by level: result[0] holds the root, result[1] holds the root’s children from left to right, result[2] holds the next level, and so on. Use a std::queue of node pointers (required: the point of the task is the queue). An empty tree returns an empty outer vector (not a vector holding one empty vector).

For the tree built from 8, 3, 10, 1, 6, 14, 4, 7, 13 the result is

[8]   [3 10]   [1 6 14]   [4 7 13]
Hint You used a queue to explore a maze one step at a time. Here the question is how to know where one level ends and the next begins. How many nodes are in the queue at the moment a new level starts?

Task D — height() and countLeaves()

height() returns the number of edges on the longest path from the root down to a leaf. A single node has height 0, and the empty tree has height -1. countLeaves() returns the number of nodes that have no children; the empty tree has 0 leaves.

Both are short recursive functions. Check them against the tree you drew in the warm-up.

Hint Ask each subtree for its answer, and combine the two answers with the node itself. Take care with the empty tree and with a node that has only one child: an empty subtree is not a leaf.

Edge Cases to Test

Write a few small calls of your own in a scratch main before submitting. Check at least:

  • the empty tree (nullptr) in every function;
  • a tree with a single node;
  • a tree where every node has only a left child, and one where every node has only a right child;
  • a node with exactly one child (not two, not zero);
  • for Task A, an out that already holds some values;
  • for Task B, the sequences agree with Task A on every tree you try.

Tree.cpp

// Tree.cpp
// CSCI 235 -- Exercise 10: BST Traversal
// Provided file -- do not modify, do not submit. Compile it together with
// your Traversal.cpp (see the handout).

#include "Tree.hpp"

Node* insert(Node* root, int value) {
    if (root == nullptr) { return new Node(value); }
    Node* curr = root;
    while (true) {
        if (value < curr->data) {
            if (curr->left == nullptr) { curr->left = new Node(value); break; }
            curr = curr->left;
        } else if (value > curr->data) {
            if (curr->right == nullptr) { curr->right = new Node(value); break; }
            curr = curr->right;
        } else {
            break;                       // duplicate: ignored
        }
    }
    return root;
}

Node* buildTree(const std::vector<int>& values) {
    Node* root = nullptr;
    for (std::size_t i = 0; i < values.size(); ++i) {
        root = insert(root, values[i]);
    }
    return root;
}

// Uses a vector of pending nodes instead of recursion, so that even a very
// deep tree can be freed.
void destroy(Node* root) {
    std::vector<Node*> pending;
    if (root != nullptr) { pending.push_back(root); }
    while (!pending.empty()) {
        Node* toDelete = pending.back();
        pending.pop_back();
        if (toDelete->left  != nullptr) { pending.push_back(toDelete->left); }
        if (toDelete->right != nullptr) { pending.push_back(toDelete->right); }
        delete toDelete;
    }
}

Ex10Demo.cpp

// Ex10Demo.cpp
// CSCI 235 -- Exercise 10: BST Traversal
//
// Provided file -- do not submit this. Build it with:
//
//     g++ -std=c++17 -g Tree.cpp Traversal.cpp Ex10Demo.cpp -o ex10demo
//     ./ex10demo
//
// The expected output is in demo_output.txt. Your output should match it
// exactly once all four tasks are done.

#include "Tree.hpp"

#include <iostream>
#include <string>
#include <vector>

static std::string show(const std::vector<int>& v) {
    std::string s;
    for (std::size_t i = 0; i < v.size(); ++i) {
        if (i > 0) { s += " "; }
        s += std::to_string(v[i]);
    }
    return s;
}

static void runTree(const char* name, const std::vector<int>& insertOrder) {
    Node* root = buildTree(insertOrder);
    std::cout << name << "  (inserted: " << show(insertOrder) << ")\n";

    std::vector<int> a;
    inorder(root, a);
    std::cout << "  inorder            : " << show(a) << "\n";
    a.clear();
    preorder(root, a);
    std::cout << "  preorder           : " << show(a) << "\n";
    a.clear();
    postorder(root, a);
    std::cout << "  postorder          : " << show(a) << "\n";

    std::cout << "  inorderIterative   : " << show(inorderIterative(root)) << "\n";
    std::cout << "  preorderIterative  : " << show(preorderIterative(root)) << "\n";

    std::vector<std::vector<int>> levels = levelOrder(root);
    std::cout << "  levelOrder         :";
    for (std::size_t i = 0; i < levels.size(); ++i) {
        std::cout << " [" << show(levels[i]) << "]";
    }
    std::cout << "\n";

    std::cout << "  height " << height(root) << ", leaves " << countLeaves(root) << "\n\n";
    destroy(root);
}

int main() {
    runTree("Tree 1", {8, 3, 10, 1, 6, 14, 4, 7, 13});
    runTree("Tree 2 (a chain)", {1, 2, 3, 4});
    runTree("Tree 3 (one node)", {5});
    runTree("Tree 4 (empty)", {});
    return 0;
}
