Learning Objectives

In this exercise, you will practice:

  • deriving subclasses from a superclass;
  • calling a superclass constructor from a subclass constructor;
  • inheriting methods whose behavior is shared by subclasses;
  • overriding a virtual method when subclasses need different behavior;
  • using a superclass pointer to work with objects of different subclasses;
  • using runtime polymorphism.

The Inheritance Hierarchy

You will work with the following inheritance hierarchy:

Shape

Square
is-a  —  every Triangle is a Shape; every Square is a Shape

A Triangle in this exercise is an equilateral triangle: all three edges have the same length. A Square has four edges of the same length.

1. The Shape Class (provided)

A Shape stores:

  • the number of edges;
  • the length of each edge.

Both data members are private. Derived classes access them through the public methods numEdges() and edgeLength().

The perimeter() method behaves the same for both a triangle and a square: 

perimeter = number of edges × edge length

Therefore, subclasses simply inherit perimeter() — you do not override it.

The calculation of area, however, depends on the type of shape. Therefore, area() is declared virtual in Shape.

Shape.hpp

#ifndef SHAPE_HPP
#define SHAPE_HPP

class Shape {
public:
    Shape();
    Shape(int numEdges, double edgeLength);

    int numEdges() const;
    double edgeLength() const;

    virtual double area() const;
    double perimeter() const;

private:
    int numEdges_;
    double edgeLength_;
};

#endif

Shape.cpp

#include "Shape.hpp"

Shape::Shape()
    : numEdges_(1), edgeLength_(1) {
}

Shape::Shape(int numEdges, double edgeLength)
    : numEdges_(numEdges > 0 ? numEdges : 1),
      edgeLength_(edgeLength > 0 ? edgeLength : 1) {
}

int Shape::numEdges() const {
    return numEdges_;
}

double Shape::edgeLength() const {
    return edgeLength_;
}

double Shape::area() const {
    return 0;   // placeholder for a general Shape
}

double Shape::perimeter() const {
    return numEdges_ * edgeLength_;
}

2. Implement Triangle

Create Triangle.hpp and Triangle.cpp. Triangle publicly inherits from Shape.

Requirements

Triangle must provide:

Triangle();
Triangle(double edgeLength);
double area() const override;

The default constructor creates an equilateral triangle whose edge length is 2. Therefore Triangle() should initialize the Shape portion with 3 edges and edge length 2.

The parameterized constructor Triangle(double edgeLength) creates an equilateral triangle having the specified edge length.

Design constraint Do not add additional data members to Triangle. The edge length is already stored in the superclass — access it through the inherited edgeLength() method.

Calculate the area of an equilateral triangle using:

area = (√3 / 4) × edgeLength²

Use <cmath> for std::sqrt(). Use the qualified name std::sqrt, not a bare sqrt.

3. Implement Square

Create Square.hpp and Square.cpp. Square publicly inherits from Shape.

Requirements

Square must provide:

Square();
Square(double edgeLength);
double area() const override;

The default constructor creates a square whose edge length is 2. Therefore Square() should initialize the Shape portion with 4 edges and edge length 2.

Design constraint Do not add additional data members to Square.

The area of a square is:

area = edgeLength²

Expected Behavior

For:

Square sq(5);

the triangle should print:

number of edges3
edge length6
perimeter18
areaapproximately 15.5885  (√3/4 × 6² = 9√3)

and the square should print:

number of edges4
edge length5
perimeter20
area25
On floating-point output Say approximately 15.5885 — your area does not need to match one exact textual representation. Small differences in the last printed digit, depending on how you print double values, are expected and fine.
