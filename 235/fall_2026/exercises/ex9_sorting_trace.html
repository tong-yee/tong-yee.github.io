Learning Objectives

This exercise turns the quadratic sorts from class into code. Each sort also reports its own work, so you can check your hand traces against what the program does. By the end of it you should be able to:

  • write selection sort by keeping the index of the smallest element seen so far (minIdx);
  • write bubble sort with an early exit, using a swapped flag;
  • write insertion sort by saving the element in toInsert and shifting larger elements right;
  • count comparisons and moves exactly, and see how they depend on the input (sorted, reversed, with duplicates);
  • explain what stable means and why a strict comparison (>, not >=) makes insertion sort stable.
An analogy: sorting a hand of cards Selection sort scans the whole hand for the smallest card and puts it first. Bubble sort keeps swapping two neighbouring cards that are in the wrong order. Insertion sort picks up one card at a time and slides it left into its place among the cards you already hold. In this exercise you also keep a tally of how many cards you looked at (comparisons) and how many you moved.

What “comparisons” and “moves” mean A comparison is a test between two elements of the array, such as a[j] < a[minIdx]. A test on an index, such as j >= 0, is not a comparison. For selection sort and bubble sort a move is a swap. For insertion sort a move is a shift: a copy a[j+1] = a[j]. Writing toInsert into its final gap is not counted. Each task spells out the rule; follow it exactly, because the autograder checks the counts as well as the sorted array.

Task A — selectionSort()

Sort the vector into increasing order. Pass i (for i = 0, 1, …, n-2) finds the index of the smallest element of a[i..n-1] in a variable named minIdx, and then swaps that element into position i. Do the swap only when minIdx != i.

Return a SortStats: comparisons is the number of tests a[j] < a[minIdx], and moves is the number of swaps you actually performed. An array with zero or one elements returns {0, 0}.

Hint Store an index, not a value: you need to know where the smallest element is in order to swap it. Use int loop variables and compute n once as static_cast<int>(a.size()): with an unsigned size_t, the expression n - 2 is a huge number when n is 0 or 1.

Task B — bubbleSort()

Sort the vector into increasing order. Pass i (for i = n-1, n-2, …, 1) compares neighbours a[j] and a[j+1] for j = 0, 1, …, i-1 and swaps them when a[j] > a[j+1]. Keep a bool swapped for the pass. If a complete pass makes no swap, the array is sorted, so stop at once.

comparisons counts every test a[j] > a[j+1]; moves counts the swaps. The pass that discovers there is nothing to swap still makes its comparisons. An array with zero or one elements returns {0, 0}.

Hint On an already sorted array of 6 elements, how many comparisons should your code make? If your answer is not 5, the early exit is missing.

Task C — insertionSort()

Sort the vector into increasing order. For i = 1, 2, …, n-1, save a[i] in toInsert, shift every element of a[0..i-1] that is strictly greater than toInsert one place to the right, and write toInsert into the gap.

comparisons counts every test a[j] > toInsert: both the ones that are true (and cause a shift) and the one that is false (and stops the loop). When the loop stops because j reached -1, there is no such test, because j >= 0 compares indices, not elements. moves counts the shifts only; writing toInsert is not a shift.

Hint Test j >= 0 before you read a[j]. Reading a[-1] is undefined behavior: it may appear to work on your machine and still crash on Gradescope.

Task D — stableSortCards()

A Card has a rank and a suit. Sort a vector of cards into increasing order of rank only. A sort is stable if cards of equal rank keep the order they had before the sort: if 5H was in front of 5C, it must still be in front afterwards. Write your own sort (the insertion sort from Task C, adapted to Card, works). Do not call std::sort, std::stable_sort or std::partial_sort, and do not use a sorted container (std::multiset, std::multimap, std::priority_queue); a submission that does earns no credit for this task. You may name your own helper functions anything you like.

Hint Compare cards[j].rank with toInsert.rank, and shift only when the card on the left is strictly greater. Move whole Card objects, not just the ranks, or the suits will be left behind.

Edge Cases to Test

Write a few small calls of your own in a scratch main before submitting. Check at least:

  • an empty vector and a vector of one element: no crash, and {0, 0} returned by all three int sorts;
  • two elements, in order and out of order;
  • an array that is already sorted, and one in reverse order (compare the counts with your warm-up reasoning);
  • an array with duplicates, such as {3, 1, 3, 2, 1, 2}, and one where all elements are equal;
  • negative numbers;
  • for Task D, several cards of the same rank with different suits.

Sorting.hpp

// Sorting.hpp
// CSCI 235 -- Exercise 9: Sorting Trace
// Provided file -- do not modify. Gradescope compiles your submission
// against the original version of this file.

#ifndef SORTING_HPP
#define SORTING_HPP

#include <vector>

// What a sort reports about its own work.
//   comparisons : how many times the sort compared two ELEMENTS of the array
//                 (a comparison of two indices, such as j >= 0, does not count).
//   moves       : selectionSort and bubbleSort: the number of SWAPS performed.
//                 insertionSort: the number of SHIFTS (an element copied one
//                 place to the right). Each task below says exactly what to count.
struct SortStats {
    int comparisons;
    int moves;
};

// Task A -- selection sort. Sort a into increasing order.
// Pass i (i = 0, 1, ..., n-2) finds the index of the smallest element of
// a[i..n-1] in the variable minIdx and swaps it into position i, but only
// when minIdx != i (never swap an element with itself).
//   comparisons: one for every test  a[j] < a[minIdx]   (always n(n-1)/2)
//   moves:       the number of swaps actually performed
// An array with 0 or 1 elements returns {0, 0}.
SortStats selectionSort(std::vector<int>& a);

// Task B -- bubble sort with an early exit.
// Pass i (i = n-1, n-2, ..., 1) compares neighbours a[j] and a[j+1] for
// j = 0, 1, ..., i-1 and swaps them when a[j] > a[j+1]. If a whole pass
// makes no swap, the array is sorted: stop at once.
//   comparisons: one for every test  a[j] > a[j+1]
//   moves:       the number of swaps performed
// An array with 0 or 1 elements returns {0, 0}.
SortStats bubbleSort(std::vector<int>& a);

// Task C -- insertion sort. For i = 1, 2, ..., n-1: save a[i] in toInsert,
// shift every element of a[0..i-1] that is STRICTLY greater than toInsert
// one place to the right, and put toInsert into the gap.
//   comparisons: one for every test  a[j] > toInsert
//                (the test  j >= 0  is not a comparison of elements)
//   moves:       the number of shifts (writes of the form a[j+1] = a[j]);
//                placing toInsert into the gap is NOT counted
// An array with 0 or 1 elements returns {0, 0}.
SortStats insertionSort(std::vector<int>& a);

// Task D -- a STABLE sort of cards by rank.
struct Card {
    int  rank;     // the sort key, for example 2 .. 14
    char suit;     // 'C', 'D', 'H' or 'S'; NOT part of the comparison
};
// Sort cards into increasing order of rank. Cards of equal rank must keep the
// order they had before the sort (that is what STABLE means).
// Write your own sort (insertion sort with a strict comparison works well).
// Do not call std::sort, std::stable_sort or std::partial_sort, and do not use a
// sorted container (std::multiset, std::multimap, std::priority_queue).
void stableSortCards(std::vector<Card>& cards);

#endif

Ex9Demo.cpp

// Ex9Demo.cpp
// CSCI 235 -- Exercise 9: Sorting Trace
//
// Provided file -- do not submit this. Build it with:
//
//     g++ -std=c++17 -g Sorting.cpp Ex9Demo.cpp -o ex9demo
//     ./ex9demo
//
// The expected output is in demo_output.txt. Your output should match it
// exactly once all four tasks are done.

#include "Sorting.hpp"

#include <iostream>
#include <string>
#include <vector>

static std::string show(const std::vector<int>& a) {
    std::string s;
    for (std::size_t i = 0; i < a.size(); ++i) {
        if (i > 0) { s += " "; }
        s += std::to_string(a[i]);
    }
    return s;
}

static std::string showCards(const std::vector<Card>& c) {
    std::string s;
    for (std::size_t i = 0; i < c.size(); ++i) {
        if (i > 0) { s += " "; }
        s += std::to_string(c[i].rank);
        s += c[i].suit;
    }
    return s;
}

static void runInt(const char* name, SortStats (*sorter)(std::vector<int>&),
                   std::vector<int> a) {
    std::cout << "  " << name << ": " << show(a) << "  ->  ";
    SortStats st = sorter(a);
    std::cout << show(a) << "   comparisons=" << st.comparisons
              << " moves=" << st.moves << "\n";
}

int main() {
    const std::vector<int> start = {5, 2, 4, 6, 1, 3};
    const std::vector<int> sorted = {1, 2, 3, 4, 5, 6};
    const std::vector<int> reversed = {6, 5, 4, 3, 2, 1};

    std::cout << "=== Task A: selectionSort ===\n";
    runInt("start   ", selectionSort, start);
    runInt("sorted  ", selectionSort, sorted);
    runInt("reversed", selectionSort, reversed);

    std::cout << "\n=== Task B: bubbleSort ===\n";
    runInt("start   ", bubbleSort, start);
    runInt("sorted  ", bubbleSort, sorted);
    runInt("reversed", bubbleSort, reversed);

    std::cout << "\n=== Task C: insertionSort ===\n";
    runInt("start   ", insertionSort, start);
    runInt("sorted  ", insertionSort, sorted);
    runInt("reversed", insertionSort, reversed);

    std::cout << "\n=== Task D: stableSortCards ===\n";
    std::vector<Card> cards = {{5, 'H'}, {3, 'S'}, {5, 'C'}, {2, 'D'}, {3, 'H'}};
    std::cout << "  before: " << showCards(cards) << "\n";
    stableSortCards(cards);
    std::cout << "  after : " << showCards(cards) << "\n";
    return 0;
}
