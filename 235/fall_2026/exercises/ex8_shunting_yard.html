Learning Objectives

This exercise turns Class 18 into code, and it is the engine inside Project 4. By the end of it you should be able to:

  • split a string into tokens, keeping a multi-digit number together as one token;
  • evaluate a postfix expression with a std::stack, remembering that the first value popped is the right operand;
  • convert infix to postfix with the shunting-yard algorithm, using an operator stack and an output queue;
  • explain how precedence, left associativity and parentheses decide when an operator leaves the stack;
  • combine three small, separately tested functions into one working program.
An analogy: a railway siding Numbers are cars that roll straight through to the output track. Operators are cars that must wait on a short siding (the stack). When a new operator arrives, any waiting operator that is at least as strong rolls out first; a ( “locks” the siding until its matching ) arrives. The name shunting yard is exactly this picture.

Task A — tokenize()

Split the text into tokens: a whole number is one token, and each operator or parenthesis is one token. Spaces are skipped and never become tokens (skipping any whitespace character with std::isspace is fine; the tests use ordinary spaces). Spaces are optional, so "12+3" and "12 + 3" both give {"12", "+", "3"}.

Hint Walk through the string with an index. When you meet a digit, keep going while the next characters are still digits, then push the number once. The index must move forward in every branch of your loop.

Task B — evalPostfix()

Evaluate a postfix expression held in a queue of tokens. Use a std::stack<double>. A number is pushed; an operator pops two values, applies the operator, and pushes the result. The queue is passed by value, so you may empty your copy.

The order of the two pops matters for - and /: the value popped first is the right operand. If the operator is / and the right operand is zero (test b == 0.0, an exact comparison), throw std::runtime_error instead of dividing. (std::invalid_argument is a different class and will not match what the tests expect.)

Hint For 8 3 -, the stack holds 8 then 3 with 3 on top. Which of the two is the left operand?

Task C — toPostfix()

Convert a vector of infix tokens to a queue of postfix tokens with the shunting-yard algorithm. Use an output queue and a std::stack<std::string> of operators. Parentheses are used but never written to the output. All four operators are left-associative: when a new operator arrives, an operator of equal or higher precedence on top of the stack leaves first.

For example, 3 + 4 * 2 becomes 3 4 2 * +, while (3 + 4) * 2 becomes 3 4 + 2 *, and 8 - 3 - 2 becomes 8 3 - 2 -.

Hint Your warm-up table already is the algorithm. For an operator, the question is a while loop: while the stack is not empty, the top is an operator (not a (), and the top is at least as strong as the new one, move the top to the output.

Task D — evaluate()

Evaluate infix text from start to finish: tokenize it, convert it to postfix, and evaluate the postfix result. This function is short; its point is to see that three small, tested pieces make a calculator. A division by zero is not caught here: the exception from Task B passes straight through.

Edge Cases to Test

Write a few small calls of your own in a scratch main before submitting. Check at least:

  • tokenize("") and tokenize(" "): no tokens, and no crash;
  • a number with several digits, such as 120, in the middle of an expression;
  • no spaces at all: "100/(5*4)";
  • 8 - 3 - 2 and 12 / 3 / 2: equal operators must leave left to right;
  • nested parentheses: ((1 + 2) * 3);
  • an expression that is just (7);
  • a division whose right side is computed to zero, such as 8 / (4 - 4);
  • real division: 7 / 2 is 3.5, and 9 / 4 is 2.25;

Postfix.hpp

// Postfix.hpp
// CSCI 235 -- Exercise 8: Shunting-Yard Trace
// Provided file -- do not modify. Gradescope compiles your submission
// against the original version of this file.

#ifndef POSTFIX_HPP
#define POSTFIX_HPP

#include <queue>
#include <string>
#include <vector>

// Input assumptions for every function below (a VALID-INPUT exercise):
//   * numbers are nonnegative integers such as 7 or 120 (no decimals, no
//     unary minus);
//   * operators are the four binary operators + - * /;
//   * parentheses are balanced;
//   * "/" is real (floating-point) division: 7 / 2 is 3.5, as in Project 4.
// Project 4 will ask you to reject bad input; this exercise does not.
// The only empty-input case that is specified is tokenize() (see Task A);
// the other functions assume a nonempty, valid expression.

// Task A -- split text into tokens. A token is one whole number ("12"), or a
// single operator or parenthesis character. Spaces separate tokens but are
// never tokens themselves, and spaces are optional: "12+3" and "12 + 3"
// give the same tokens {"12", "+", "3"}. Skipping any whitespace character
// (std::isspace) is fine. tokenize("") and tokenize("   ") return an
// empty vector.
std::vector<std::string> tokenize(const std::string& text);

// Task B -- evaluate a postfix expression with a stack. The queue holds
// tokens in postfix order, for example 3 4 2 * +  (which is 11).
// For each operator, the value popped FIRST is the RIGHT operand.
// If an operator "/" would divide by zero (right operand == 0.0, an exact
// test), throw std::runtime_error.
// Values are doubles, so the result can have a fractional part.
double evalPostfix(std::queue<std::string> postfix);

// Task C -- convert infix tokens to postfix with the shunting-yard
// algorithm. All four operators are left-associative: * and / bind tighter
// than + and -, and an operator of EQUAL precedence already on the stack
// leaves first, so 8 - 3 - 2 becomes 8 3 - 2 - . Parentheses are never
// written to the output.
std::queue<std::string> toPostfix(const std::vector<std::string>& tokens);

// Task D -- evaluate infix text from start to finish by combining the three
// tasks above: tokenize, convert, then evaluate. A division by zero throws
// std::runtime_error, exactly as in Task B.
double evaluate(const std::string& text);

#endif

// Ex8Demo.cpp
// CSCI 235 -- Exercise 8: Shunting-Yard Trace
//
// Provided file -- do not submit this. Build it with:
//
//     g++ -std=c++17 -g Postfix.cpp Ex8Demo.cpp -o ex8demo
//     ./ex8demo
//
// The expected output is in demo_output.txt. Your output should match it
// exactly once all four tasks are done.

#include "Postfix.hpp"

#include <iostream>
#include <queue>
#include <stdexcept>
#include <string>
#include <vector>

static std::string join(std::queue<std::string> q) {
    std::string s;
    while (!q.empty()) {
        s += q.front();
        q.pop();
        if (!q.empty()) { s += " "; }
    }
    return s;
}

int main() {
    std::cout << "=== Task A: tokenize ===\n";
    for (const char* text : {"3 + 4 * 2", "12+3*(4-1)", "(7)"}) {
        std::vector<std::string> t = tokenize(text);
        std::cout << "  \"" << text << "\" -> " << t.size() << " tokens:";
        for (const std::string& tok : t) { std::cout << " [" << tok << "]"; }
        std::cout << "\n";
    }

    std::cout << "\n=== Task B: evalPostfix ===\n";
    for (const char* text : {"3 4 2 * +", "3 4 + 2 *", "8 3 - 2 -", "7 2 /"}) {
        std::queue<std::string> q;
        for (const std::string& tok : tokenize(text)) { q.push(tok); }
        std::cout << "  " << text << "  =  " << evalPostfix(q) << "\n";
    }
    try {
        std::queue<std::string> q;
        for (const std::string& tok : tokenize("5 0 /")) { q.push(tok); }
        evalPostfix(q);
        std::cout << "  5 0 /  did not throw\n";
    } catch (const std::runtime_error& e) {
        std::cout << "  5 0 /  throws: " << e.what() << "\n";
    }

    std::cout << "\n=== Task C: toPostfix ===\n";
    for (const char* text : {"3 + 4 * 2", "(3 + 4) * 2", "8 - 3 - 2",
                             "5 + (1 + 2) * 4 - 3", "12 / (2 + 1) - 1"}) {
        std::cout << "  " << text << "  ->  " << join(toPostfix(tokenize(text))) << "\n";
    }

    std::cout << "\n=== Task D: evaluate ===\n";
    for (const char* text : {"3 + 4 * 2", "(3 + 4) * 2", "8 - 3 - 2",
                             "5 + (1 + 2) * 4 - 3", "12 / (2 + 1) - 1",
                             "7 / 2", "9 / 4", "(2 + 3) * (4 - 1)", "100/(5*4)"}) {
        std::cout << "  " << text << "  =  " << evaluate(text) << "\n";
    }
    return 0;
}
