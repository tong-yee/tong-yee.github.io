Learning Objectives

Recursion (Class 11) and queues (Class 10) meet in the BFS you saw in Class 12. This exercise puts the two together in a small game. By the end of it you should be able to:

  • write a recursive function with a base case and a recursive case that works on a smaller problem, where “smaller” can mean a smaller number (k) or a smaller queue;
  • use only the queue operations front(), push(), pop(), size() and empty() — no peeking inside;
  • see that the call stack remembers things for you: a recursive function can hold a value in a local variable while the smaller problem is solved, and then use it afterwards;
  • get the same answer in two ways — by simulating a process with a queue, and by a recursive formula — and explain why the two agree.
The game: hot potato A group of people stands in a circle and passes a potato. After the potato has been passed k times, the person holding it leaves the circle. The potato keeps going around with one person fewer, until only one person is left: the winner. A queue models the circle perfectly. Passing the potato means the person at the front steps to the back of the line. Leaving the circle means a person is removed from the front.

Task A — rotate()

Move the front element to the back, k times, recursively. For example [1 2 3 4 5] rotated by 2 is [3 4 5 1 2]. If the queue is empty, nothing happens. Here the thing that gets smaller is the number k, not the queue.

Hint What is the easiest value of k? What does one move accomplish, and how many moves are left after it? Remember that k may be larger than the size of the queue.

Task B — reverseQueue()

Reverse the elements of the queue in place. For example [1 2 3 4] becomes [4 3 2 1]. You may not use any other container: no vector, no stack, no second queue. The recursion itself must do the remembering.

Hint Remove the front element and keep it in a local variable. Suppose a recursive call has already reversed the rest. Where does your element belong now? Check the trace you drew in the warm-up.

Task C — hotPotato()

Play the game and return the winner’s value. Each round, pass the potato k times (the front person moves to the back, k times, exactly like rotate(q, k) in Task A), and then the person at the front is out. Rounds repeat until one person is left. Worked example, [1 2 3 4 5] with k = 2:

RoundQueue at the startAfter passing twiceLeaves
1[1 2 3 4 5][3 4 5 1 2]3
2[4 5 1 2][1 2 4 5]1
3[2 4 5][5 2 4]5
4[2 4][2 4]2

The winner is 4. (In round 4 the potato is passed twice among two people, so it ends up where it started.) When your function returns, the queue holds exactly one element, the winner.

You may call your own rotate() from Task A to pass the potato. If you do, a bug in Task A will also lose you points in Task C, so test Task A first.

Hint One round leaves you with a smaller game of the same kind. What is the smallest game, the one you can answer without playing a round?

Task D — survivorPosition()

The same game, answered without a queue. Number the people 0, 1, …, n-1 in queue order. survivorPosition(n, k) returns the number of the winner. It has a recursive definition:

n = 1the only person, number 0, wins
n > 1survivorPosition(n, k) = ( survivorPosition(n − 1, k) + k + 1 ) mod n

Why does it work? After the first person leaves, the circle has n − 1 people, and the new front of the circle is the person who stood at position k + 1 (counting from 0, wrapping around) in the old circle, so every number from the smaller game is shifted by k + 1 and wrapped around the circle of n. You do not need to prove this. You do need to check it: for [1 2 3 4 5] and k = 2, the formula gives position 3, which is the person labeled 4, the winner of the worked example above. If the queue holds the values 1..n in order, hotPotato(q, k) equals survivorPosition(n, k) + 1.

Hint This one is almost a translation of the table. Which row is the base case, and which is the recursive call?

Edge Cases to Test

Write a few small calls of your own in a scratch main before submitting. Check at least:

  • rotate with k = 0, with k equal to the size, with k larger than the size, and on an empty queue;
  • reverseQueue on an empty queue, a one-element queue, and a two-element queue;
  • hotPotato with one person, with two people, and with k = 0 (the potato is never passed);
  • survivorPosition(1, k) for any k;
  • whether hotPotato and survivorPosition agree for n = 1..10 and a few values of k.

Remember that front() on an empty queue is undefined behavior: it may crash, or it may appear to work and give garbage. Check empty() or size() first.

RecQueue.hpp

// RecQueue.hpp
// CSCI 235 -- Exercise 6: Recursion and Queues
// Provided file -- do not modify. Gradescope compiles your submission
// against the original version of this file.

#ifndef RECQUEUE_HPP
#define RECQUEUE_HPP

#include <queue>
#include <vector>

// Every function below must be RECURSIVE: do not use a loop (for, while) to
// do the repeating that a recursive call is supposed to do.
//
// The only queue operations you need are front(), back(), push(), pop(),
// empty() and size() from std::queue<int>.

// Task A -- Move the front element to the back, k times.
// Example: q = [1 2 3 4 5], k = 2  ->  q = [3 4 5 1 2].
// Precondition: k >= 0. If q is empty, nothing happens. Afterwards the
// elements of q are the same ones, in the rotated order.
void rotate(std::queue<int>& q, int k);

// Task B -- Reverse the order of the elements of q, in place.
// Example: q = [1 2 3 4] -> q = [4 3 2 1]. An empty or one-element queue is
// left alone. No other container (no vector, no stack) may be used: the
// recursion's own call stack does the remembering.
void reverseQueue(std::queue<int>& q);

// Task C -- The "hot potato" game. The people in q are standing in a circle,
// front of the queue first. Each round, the potato is passed k times (the
// person at the front moves to the back, k times, exactly as in rotate()),
// and then the person now at the front is OUT of the game (removed). Rounds
// repeat until only one person is left. Return that person's value.
//
// Example: q = [1 2 3 4 5], k = 2.
//   Round 1: pass twice ([3 4 5 1 2]), remove 3.   q = [4 5 1 2]
//   Round 2: pass twice ([1 2 4 5]),   remove 1.   q = [2 4 5]
//   Round 3: pass twice ([5 2 4]),     remove 5.   q = [2 4]
//   Round 4: pass twice ([2 4]),       remove 2.   q = [4]    -> returns 4
//
// With k = 0 the potato is never passed: the front person leaves every round.
//
// Preconditions: q is not empty, 0 <= k <= 100. When the call returns,
// q holds exactly one element, the winner.
// You may call your own rotate() from Task A, but then Task C inherits any
// bug that Task A has.
int hotPotato(std::queue<int>& q, int k);

// Task D -- The same game as a formula. People are numbered 0, 1, ..., n-1
// in queue order. Return the NUMBER (0-based position in the original
// queue) of the person who wins. Recursive definition:
//   n == 1:  the only person, position 0, wins.
//   n  > 1:  see the handout.
// Preconditions: n >= 1, 0 <= k <= 100.
// Check: if q holds the values 1..n in order, then
//   hotPotato(q, k) == survivorPosition(n, k) + 1.
int survivorPosition(int n, int k);

#endif

Ex6Demo.cpp

// Ex6Demo.cpp
// CSCI 235 -- Exercise 6: Recursion and Queues
//
// Provided file -- do not submit this. Build it with:
//
//     g++ -std=c++17 -g RecQueue.cpp Ex6Demo.cpp -o ex6demo
//     ./ex6demo
//
// The expected output is in demo_output.txt. Your output should match it
// exactly once all four tasks are done.

#include "RecQueue.hpp"

#include <iostream>
#include <queue>

static std::queue<int> make(int n) {
    std::queue<int> q;
    for (int i = 1; i <= n; ++i) {
        q.push(i);
    }
    return q;
}

static void print(std::queue<int> q) {      // by value: prints a copy
    std::cout << "[";
    bool first = true;
    while (!q.empty()) {
        std::cout << (first ? "" : " ") << q.front();
        first = false;
        q.pop();
    }
    std::cout << "]";
}

int main() {
    std::cout << "=== Task A: rotate ===\n";
    for (int k : {0, 1, 2, 5, 7}) {
        std::queue<int> q = make(5);
        rotate(q, k);
        std::cout << "  rotate [1 2 3 4 5] by " << k << ": ";
        print(q);
        std::cout << "\n";
    }

    std::cout << "\n=== Task B: reverseQueue ===\n";
    for (int n : {0, 1, 2, 6}) {
        std::queue<int> q = make(n);
        std::cout << "  ";
        print(q);
        reverseQueue(q);
        std::cout << " -> ";
        print(q);
        std::cout << "\n";
    }

    std::cout << "\n=== Task C: hotPotato ===\n";
    for (int k : {0, 1, 2}) {
        std::queue<int> q = make(5);
        int w = hotPotato(q, k);
        std::cout << "  5 people, k = " << k << ": winner " << w
                  << ", queue size afterwards " << q.size() << "\n";
    }

    std::cout << "\n=== Task D: survivorPosition ===\n";
    for (int k : {1, 2}) {
        std::cout << "  k = " << k << ":";
        for (int n = 1; n <= 7; ++n) {
            std::cout << " " << survivorPosition(n, k);
        }
        std::cout << "\n";
    }
    return 0;
}
