Learning Objectives

This exercise is about pointers themselves, not about array algorithms you already know how to write with indices. By the end of it you should be comfortable with:

  • the equivalence arr[i] ≡ *(arr + i), and &arr[i] ≡ arr + i;
  • allocating and freeing a dynamic array with new[] and delete[];
  • returning a pointer into an existing array (int*), as distinct from returning a value (int);
  • walking an array with two pointers that move toward each other, instead of an integer index;
  • passing a pointer to a function so it can modify the pointee (int*), versus passing a pointer to a pointer so it can modify what the pointer itself points to (int**).
Why this matters for Project 1A MiniVector's internals — data_, reserve(), push_back() — are built entirely out of the pointer operations you practice here. This exercise is meant to help with P1A, not compete with it, so it is intentionally short: one conceptual task (A) and four small functions (B–E). Task F is optional.

Task A — Pointer Expressions

No loops and no algorithms here — work out each expression below. Suppose: 

int arr[] = {10, 20, 30, 40};
int* p = arr;

Work out each pair and determine their relationship:

ExpressionExpressionRelationship
*arrarr[0]?
*(arr + 1)arr[1]?
arr + 1&arr[1]?
*pp[0]?
*(p + 2)p[2]?

Then decide true or false:

arr + 1 == &arr[1]      // true or false?
*(arr + 2) == arr[2]    // true or false?
Takeaway You just confirmed it yourself: arr[i] is exactly *(arr + i), and &arr[i] is exactly arr + i. The compiler treats them identically — array indexing is pointer arithmetic, just with friendlier syntax. That is the bridge between the two notations you have seen for arrays.

Requirements

Hint: getting started Look at the comments next to the fields of TaskAAnswers in PointerPractice.hpp. Each comment tells you which expression that field should store. Create a TaskAAnswers object, fill in its fields, and return it.

Task B — Dynamic Allocation

int* allocate(std::size_t size);

Return a dynamically allocated array containing size integers, with every element value-initialized to 0.

Hint Use new[], and value-initialize the elements so that each one starts at 0. Whoever calls allocate() is responsible for eventually calling delete[] on what it returns — that is exactly the ownership responsibility MiniVector's destructor takes on for data_.

Requirements

Implement allocate in PointerPractice.cpp.

Task C — Pointer to the Last Minimum

int* lastMinimum(int* arr, std::size_t size);

Return a pointer to the last occurrence of the smallest value in arr — not the value itself, and not the first occurrence if the minimum appears more than once. If size == 0, return nullptr.

For example:

int arr[] = {4, 2, 7, 2, 5};
lastMinimum(arr, 5);   // returns &arr[3], the SECOND 2 -- not &arr[1]
Hint Pay attention to the return type. return arr[i]; returns an int — the wrong type here, and it will not compile against this function's declared return type. return &arr[i]; returns an int*, which is what you want: a pointer into the caller's own array, not a copy of the value.

Requirements

Implement lastMinimum in PointerPractice.cpp.

Task D — Reverse In Place

void reverse(int* arr, std::size_t size);

Reverse the elements of arr in place.

Requirement: use two pointers, not indices You must implement this with two pointers that start at opposite ends and walk toward each other, swapping as they go. Start from: 
if (size < 2) {
    return;
}

int* left = arr;
int* right = arr + size - 1;

// Use left and right to reverse the array.
Move left and right toward each other, one step at a time, swapping the two elements they point to at each step, until they meet or cross. Do not write this using arr[i] and an integer index. The point of this task is practicing pointer arithmetic (++, --, and pointer comparison with <) directly, the same way you will read and write MiniVector code.
Why the size < 2 check matters size is unsigned, so when size == 0, size - 1 underflows. Handle size < 2 before constructing right.

Requirements

Implement reverse in PointerPractice.cpp, using the two-pointer pattern above.

Task E — Two Kinds of “Swap”

void swapValues(int* a, int* b);
void swapPointers(int** a, int** b);

These two functions look similar but do genuinely different things, because int* and int** represent different levels of indirection. 

// swapValues changes the integers
int x = 10;
int y = 20;
int* p = &x;
int* q = &y;

swapValues(p, q);
// x == 20, y == 10
// p still points to x; q still points to y

// swapPointers changes the pointers
int x2 = 10;
int y2 = 20;
int* p2 = &x2;
int* q2 = &y2;

swapPointers(&p2, &q2);
// x2 == 10, y2 == 20
// p2 now points to y2; q2 now points to x2
  • swapValues(int* a, int* b) swaps the two ints that a and b point to.
  • swapPointers(int** a, int** b) swaps what the two pointers *a and *b point to — it changes the pointers themselves, not any int.
Hint Read int** the same way you read int*, one level up: int* lets a function change an int through its address; int** lets a function change an int* (a pointer) through its address. To call swapPointers you pass the address of a pointer variable, e.g. swapPointers(&p2, &q2).

Requirements

Implement both swapValues and swapPointers in PointerPractice.cpp.

Task F — Palindrome Check (optional practice)

bool isPalindrome(const int* arr, std::size_t size);

Return true if arr reads the same forwards and backwards. An empty array, or an array with a single element, counts as a palindrome.

Hint Same two-pointer pattern as Task D, but you are comparing instead of swapping, and you never modify arr — that is exactly what const int* promises the caller.

// PointerPracticeDemo.cpp
// CSCI 235 -- Exercise 2: Pointer Practice
//
// A small driver so you can compile and run your PointerPractice.cpp
// locally and see it in action before submitting. This file is
// PROVIDED for your own testing -- you do NOT submit it, and Gradescope
// does not use it; Gradescope has its own, more thorough checks.

// Compile and run with:
//   g++ -std=c++17 PointerPractice.cpp PointerPracticeDemo.cpp -o demo
//   ./demo

#include <iostream>

#include "PointerPractice.hpp"

int main() {
    std::cout << "=== Task A: pointer expressions ===\n";
    int arr[] = {10, 20, 30, 40};
    TaskAAnswers ans = taskA_pointerExpressions(arr);
    std::cout << "*arr = " << ans.starArr << "   (expect 10)\n";
    std::cout << "arr[0] = " << ans.arrBracket0 << "   (expect 10)\n";
    std::cout << "*(arr + 1) = " << ans.starArrPlus1 << "   (expect 20)\n";
    std::cout << "arr[1] = " << ans.arrBracket1 << "   (expect 20)\n";
    std::cout << "arr + 1 == &arr[1]? " << (ans.arrPlus1EqualsAddrArrBracket1 ? "true" : "false")
              << "   (expect true)\n";
    std::cout << "*p = " << ans.starP << "   (expect 10)\n";
    std::cout << "p[2] = " << ans.pBracket2 << "   (expect 30)\n";
    std::cout << "*(arr + 2) == arr[2]? "
              << (ans.starArrPlus2EqualsArrBracket2 ? "true" : "false") << "   (expect true)\n";

    std::cout << "\n=== Task B: allocate ===\n";
    int* dyn = allocate(5);
    std::cout << "dyn == nullptr? " << (dyn == nullptr ? "true" : "false")
              << "   (expect false)\n";
    if (dyn != nullptr) {
        std::cout << "dyn[0..4] = ";
        for (int i = 0; i < 5; ++i) std::cout << dyn[i] << " ";
        std::cout << "  (expect 0 0 0 0 0)\n";
    }
    delete[] dyn;

    std::cout << "\n=== Task C: lastMinimum ===\n";
    int c[] = {4, 2, 7, 2, 5};
    int* m = lastMinimum(c, 5);
    std::cout << "min value = " << (m != nullptr ? *m : -1) << "   (expect 2)\n";
    std::cout << "index of that pointer into c = "
              << (m != nullptr ? (m - c) : -1) << "   (expect 3, the LAST 2)\n";

    std::cout << "\n=== Task D: reverse ===\n";
    int d[] = {1, 2, 3, 4, 5};
    reverse(d, 5);
    std::cout << "reversed: ";
    for (int i = 0; i < 5; ++i) std::cout << d[i] << " ";
    std::cout << "  (expect 5 4 3 2 1)\n";

    std::cout << "\n=== Task E: swapValues vs. swapPointers ===\n";
    int x = 10, y = 20;
    int* p = &x;
    int* q = &y;
    swapValues(p, q);
    std::cout << "after swapValues: x = " << x << ", y = " << y << "   (expect x=20, y=10)\n";

    int x2 = 10, y2 = 20;
    int* p2 = &x2;
    int* q2 = &y2;
    swapPointers(&p2, &q2);
    std::cout << "after swapPointers: *p2 = " << *p2 << ", *q2 = " << *q2
              << "   (expect *p2=20, *q2=10 -- p2 and q2 traded places)\n";

    std::cout << "\n=== Task F (optional): isPalindrome ===\n";
    int f1[] = {1, 2, 3, 2, 1};
    int f2[] = {1, 2, 3};
    std::cout << "isPalindrome({1,2,3,2,1}) = " << (isPalindrome(f1, 5) ? "true" : "false")
              << "   (expect true)\n";
    std::cout << "isPalindrome({1,2,3}) = " << (isPalindrome(f2, 3) ? "true" : "false")
              << "   (expect false)\n";

    return 0;
}
