Learning Objectives

This exercise is entirely about the Rule of Three from Tuesday's lecture. By the end of it you should be comfortable with:

  • writing a destructor that frees exactly the memory the object owns;
  • writing a copy constructor that makes a genuine deep copy, not a copy of a pointer;
  • writing a copy assignment operator that guards against self-assignment and frees its old memory only after the new memory is safely allocated;
  • recognizing, on sight, the double-free and dangling-pointer bugs that appear when any of the three is missing;
  • computing a value (like an average) over only the elements actually stored (count_), not the full backing array (capacity_).
Why GradeBook, not MiniVector GradeBook is deliberately not MiniVector — it gives you additional practice applying the Rule of Three to a different class, reinforcing the same resource-management pattern you used in Project 1A. The sequencing: you learned the pattern in Tuesday's lecture (9/15), applied it to MiniVector in Project 1A (due 9/17), and now practice it independently on GradeBook by the following Tuesday (9/22).

The Big Three, Visually

GradeBook owns a heap array grades_ — exactly the way MiniVector owns data_. Suppose we build a, then copy it into b with GradeBook b = a;. Without a hand-written copy constructor, the compiler generates one for free — and it does the wrong thing:

When a and b both go out of scope, each destructor calls delete[] on grades_. In the left picture, that is the same address, deleted twice — undefined behavior. In the right picture, each destructor frees its own array exactly once. This is the bug your Task B code prevents; Task C prevents the analogous problem during copy assignment.

Task A — The Destructor

~GradeBook();

GradeBook owns exactly one heap allocation: grades_. Free it.

Requirements

Implement GradeBook::~GradeBook() in GradeBook.cpp.

Hint grades_ was allocated with new[]. Remember that the form of delete must match the form of new.

Task B — The Copy Constructor

GradeBook(const GradeBook& other);

Build a brand-new GradeBook that is a deep copy of other: same count_ and capacity_, but its own array holding the same grade values.

Requirements

  1. Allocate a new array of other.capacity_ doubles.
  2. Copy other.count_ elements into it, one at a time.
  3. Copy count_ and capacity_ from other.

Implement GradeBook::GradeBook(const GradeBook& other) in GradeBook.cpp.

Hint This is a constructor, so use a member initializer list for grades_, count_, and capacity_, and copy the individual grade values inside the constructor body with a loop — exactly the pattern from Tuesday's lecture slides for MiniVector::MiniVector(const MiniVector&).

Task C — The Copy Assignment Operator

GradeBook& operator=(const GradeBook& other);

Make *this a deep copy of other, replacing whatever *this owned before. Unlike the copy constructor, *this already owns memory when this function runs — that memory must be freed, but only after the new array is safely allocated.

Requirements

  1. Guard: if this == &other, return *this immediately.
  2. Allocate a new array of other.capacity_ doubles.
  3. Copy other.count_ elements into it, one at a time.
  4. Free the old array (delete[] grades_;).
  5. Point grades_ at the new array; copy count_ and capacity_ from other; return *this.

Implement GradeBook& GradeBook::operator=(const GradeBook& other) in GradeBook.cpp.

Why check for self-assignment? With the allocate-copy-free-point implementation above, gb = gb; could still work without this check, but it would unnecessarily allocate a new array and copy every element. The this == &other check detects self-assignment immediately and avoids that unnecessary work.
Hint: allocate-before-free, not free-before-allocate If you delete[] grades_; before allocating the new array, and the new new[] throws (out of memory), *this is left holding a dangling pointer. Allocate first, copy into the new array, then free the old one. This is exactly the order used for MiniVector::reserve().

Task D — average()

double average() const;

Return the average of the grades actually stored — not the average over the full capacity_ of the array.

Requirements

  1. If count_ == 0, return 0.0 (do not divide by zero).
  2. Otherwise, sum the first count_ grades in grades_, one at a time, and divide by count_.

Implement GradeBook::average() const in GradeBook.cpp.

Hint Only the first count_ slots of grades_ hold real grades — the remaining slots up to capacity_ are unused space, not zero-valued grades to average in. Sum with a loop bounded by count_, the same way you bound the copying loops in Tasks B and C.

Task E — growTo() (optional practice)

void growTo(std::size_t newCapacity);

If newCapacity is greater than the current capacity_, replace grades_ with a larger array of size newCapacity, preserving the first count_ grades already stored. If newCapacity <= capacity_, do nothing.

Hint Same four steps as operator=’s allocate/copy/free/point — except here you copy only the count_ grades that actually exist, not the full old capacity. This is precisely the resize strategy behind MiniVector::reserve() from Thursday's lecture, applied by hand instead of doubling.

Requirements

This task is optional and is not graded. If you attempt it, implement growTo in GradeBook.cpp using the allocate/copy/free/point pattern above.

Expected Behavior

These examples exercise Tasks B and C, but every average() call below also depends on your Task D implementation being correct.

Deep copy, verified by mutating one object and checking the other is unaffected:

GradeBook a(3);
a.addGrade(90);
a.addGrade(80);

GradeBook b = a;      // Task B: copy constructor
b.addGrade(70);       // modifies ONLY b

// a.count() == 2, a.average() == 85     (a is untouched)
// b.count() == 3, b.average() == 80     (b has the extra grade)

Copy assignment, replacing what the target used to own:

GradeBook c(2);
c.addGrade(100);
c = a;                 // Task C: copy assignment
c.addGrade(60);

// a unchanged: a.count() == 2, a.average() == 85
// c now holds a's two grades plus 60: c.count() == 3, c.average() == 76.67 (approx)

Self-assignment must not crash or corrupt the object:

c = c;
// c.count() and c.average() are exactly what they were before
On floating-point output Say approximately 76.67 — small differences in the last printed digit are expected and fine.

GradeBook.cpp (partial — given)

// GradeBook.cpp
// CSCI 235 -- Exercise 3: The Big Three
// Complete the TODO sections below and submit this file.

#include "GradeBook.hpp"

GradeBook::GradeBook(std::size_t capacity)
    : grades_(new double[capacity]{}), count_(0), capacity_(capacity) {
}

void GradeBook::addGrade(double grade) {
    if (count_ < capacity_) {
        grades_[count_] = grade;
        ++count_;
    }
    // If the book is full, the grade is silently dropped.
    // The optional growTo() function can increase the capacity.
}

std::size_t GradeBook::count() const { return count_; }
std::size_t GradeBook::capacity() const { return capacity_; }

// GradeBookDemo.cpp
// CSCI 235 -- Exercise 3: The Big Three
//
// A small driver so you can compile and run your GradeBook.cpp locally
// and see it in action before submitting. This file is PROVIDED for
// your own testing -- you do NOT submit it, and Gradescope does not
// use it; Gradescope has its own, more thorough checks.
//
// Compile and run with:
//   g++ -std=c++17 GradeBook.cpp GradeBookDemo.cpp -o demo
//   ./demo

#include <iostream>

#include "GradeBook.hpp"

int main() {
    std::cout << "=== Copy constructor ===\n";
    GradeBook a(3);
    a.addGrade(90);
    a.addGrade(80);

    GradeBook b = a;
    b.addGrade(70);

    std::cout << "a.count() = " << a.count() << "   (expect 2)\n";
    std::cout << "a.average() = " << a.average() << "   (expect 85)\n";
    std::cout << "b.count() = " << b.count() << "   (expect 3)\n";
    std::cout << "b.average() = " << b.average() << "   (expect 80)\n";

    std::cout << "\n=== Copy assignment ===\n";
    GradeBook c(2);
    c.addGrade(100);
    c = a;
    c.addGrade(60);

    std::cout << "a.count() = " << a.count() << "   (expect 2, unchanged)\n";
    std::cout << "a.average() = " << a.average() << "   (expect 85, unchanged)\n";
    std::cout << "c.count() = " << c.count() << "   (expect 3)\n";
    std::cout << "c.average() = " << c.average() << "   (expect approx 76.67)\n";

    std::cout << "\n=== Self-assignment ===\n";
    std::size_t beforeCount = c.count();
    double beforeAvg = c.average();
    c = c;
    std::cout << "c.count() unchanged? "
              << (c.count() == beforeCount ? "true" : "false") << "   (expect true)\n";
    std::cout << "c.average() unchanged? "
              << (c.average() == beforeAvg ? "true" : "false") << "   (expect true)\n";

    std::cout << "\n=== Task E (optional): growTo ===\n";
    GradeBook d(2);
    d.addGrade(10);
    d.addGrade(20);
    d.growTo(4);
    d.addGrade(30);
    std::cout << "d.capacity() = " << d.capacity() << "   (expect 4)\n";
    std::cout << "d.count() = " << d.count() << "   (expect 3)\n";
    std::cout << "d.average() = " << d.average() << "   (expect 20)\n";

    return 0;
}
